## સ્થાપન Rust સ્થાપિત કરવા માટે, તમારે `rustup` નામનું સાધન વાપરવું પડશે. `rustup` એ Rust ના સંકલન (compiler), `cargo` (ક્રેટ નિર્માણ વ્યવસ્થાપક), અને અન્ય જરૂરી ઘટકોનું સંચાલન કરે છે. તમે `rustup` ને આ વેબસાઇટ પરથી ડાઉનલોડ કરી શકો છો: <https://www.rust-lang.org/tools/install>. ડાઉનલોડ કર્યા પછી, સ્થાપના સૂચનાઓનું પાલન કરો. મોટાભાગના કિસ્સાઓમાં, તમે ફક્ત સ્થાપક ચલાવીને અને પ્રક્રિયાને અનુસરીને પૂર્ણ કરી શકશો. સ્થાપન પછી, ખાતરી કરો કે `rustc` (Rust સંકલક) અને `cargo` તમારા PATH પર ઉપલબ્ધ છે. આ સામાન્ય રીતે સ્થાપન દરમિયાન આપમેળે થાય છે, પરંતુ જો તમને કોઈ સમસ્યા આવે તો તમારે તેને જાતે ગોઠવવાની જરૂર પડી શકે છે. તમે આદેશ વાક્યમાં `rustc --version` અને `cargo --version` લખીને ચકાસી શકો છો કે Rust યોગ્ય રીતે સ્થાપિત થયું છે કે નહીં. આ આદેશો Rust અને Cargo ના સંસ્કરણો પ્રદર્શિત કરશે.

સૌ પ્રથમ પગલું એ Rust સ્થાપિત કરવાનું છે. અમે `rustup` દ્વારા Rust ડાઉનલોડ કરીશું, જે Rust આવૃત્તિઓ અને સંલગ્ન સાધનોનું વ્યવસ્થાપન કરવા માટેનું કમાન્ડ લાઇન સાધન છે. ડાઉનલોડ માટે તમારે ઇન્ટરનેટ જોડાણની જરૂર પડશે.

નોંધ: જો તમે કોઈ કારણસર `rustup` વાપરવાનું પસંદ ન કરો, તો વધુ વિકલ્પો માટે કૃપા કરીને Other Rust Installation Methods પૃષ્ઠ જુઓ.

આગળના પગલાં Rust સંકલકની નવીનતમ સ્થિર આવૃત્તિ સ્થાપિત કરે છે. Rustની સ્થિરતા ખાતરીઓ સુનિશ્ચિત કરે છે કે પુસ્તકમાં આપેલા તમામ ઉદાહરણો જે `compile` થાય છે, તે નવા Rust વર્ઝન સાથે પણ `compile` થતા રહેશે. આઉટપુટ સંસ્કરણો વચ્ચે થોડું અલગ હોઈ શકે છે કારણ કે Rust ઘણીવાર ભૂલ સંદેશાઓ અને ચેતવણીઓમાં સુધારો કરે છે. બીજા શબ્દોમાં કહીએ તો, તમે આ પગલાંઓનો ઉપયોગ કરીને સ્થાપિત કરેલું Rustનું કોઈપણ નવું, સ્થિર સંસ્કરણ આ પુસ્તકની સામગ્રી સાથે અપેક્ષા મુજબ કાર્ય કરશે.

### આદેશ વાક્ય સંકેત

આ પ્રકરણમાં અને સમગ્ર પુસ્તકમાં, અમે ટર્મિનલમાં વપરાતા કેટલાક આદેશો દર્શાવીશું. જે લીટીઓ તમારે ટર્મિનલમાં દાખલ કરવાની છે તે બધા `$` થી શરૂ થાય છે. તમારે `$` અક્ષર ટાઈપ કરવાની જરૂર નથી; તે દરેક આદેશની શરૂઆત દર્શાવવા માટે કમાન્ડ લાઇન પ્રોમ્પ્ટ છે. જે લીટીઓ `$` થી શરૂ થતી નથી, તે સામાન્ય રીતે અગાઉના આદેશનું પરિણામ દર્શાવે છે. વધુમાં, PowerShell-વિશિષ્ટ ઉદાહરણો `>` નો ઉપયોગ કરશે તેના બદલે `$` નો.

### લિનક્સ અથવા મેકઓએસ પર `rustup` સ્થાપિત કરવું.

જો તમે લિનક્સ અથવા મેકઓએસ વાપરી રહ્યા છો, તો એક ટર્મિનલ ખોલો અને નીચેનો આદેશ દાખલ કરો:

$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
આદેશ એક સ્ક્રિપ્ટ ડાઉનલોડ કરે છે અને `rustup` સાધનનું સ્થાપન શરૂ કરે છે, જે Rust નું નવીનતમ સ્થિર સંસ્કરણ સ્થાપિત કરે છે. તમને તમારા પાસવર્ડ માટે પૂછવામાં આવી શકે છે. જો સ્થાપન સફળ થાય, તો નીચેની લીટી દેખાશે:

Rust is installed now. Great!
તમને એક લિંકર પણ જરૂરી થશે, જે એક એવું કાર્ય છે કે જે Rust તેના સંકલિત પરિણામોને એક ફાઈલમાં જોડવા માટે વાપરે છે. શક્ય છે કે તમારી પાસે તે પહેલાથી જ હોય. જો તમને લિંકરની ભૂલો આવે, તો તમારે C સંકલક સ્થાપિત કરવો જોઈએ, જેમાં સામાન્ય રીતે લિંકરનો સમાવેશ થાય છે. C સંકલક એ પણ ઉપયોગી છે કારણ કે કેટલાક સામાન્ય Rust ક્રેટ્સ C કોડ પર આધાર રાખે છે અને તેમને C સંકલકની જરૂર પડશે.

macOS પર, તમે આ કાર્યકારી કમાન્ડ ચલાવીને C સંકલક મેળવી શકો છો:

$ xcode-select --install
લિનક્સ વપરાશકર્તાઓએ સામાન્ય રીતે તેમના વિતરણની દસ્તાવેજીકરણ અનુસાર GCC અથવા Clang સ્થાપિત કરવું જોઈએ. ઉદાહરણ તરીકે, જો તમે Ubuntu વાપરતા હોવ, તો તમે `build-essential` પેકેજ સ્થાપિત કરી શકો છો.

### વિન્ડોઝ પર `rustup` સ્થાપિત કરવું

વિન્ડોઝ પર, https://www.rust-lang.org/tools/install ની મુલાકાત લો અને Rust સ્થાપિત કરવા માટેની સૂચનાઓ અનુસરો. સ્થાપન દરમિયાન કોઈ તબક્કે, તમને Visual Studio સ્થાપિત કરવાનું કહેવામાં આવશે. આ એક લિંકર અને પ્રોગ્રામ્સને સંકલિત કરવા માટે જરૂરી મૂળ લાઇબ્રેરીઓ પૂરી પાડે છે. જો તમને આ પગલામાં વધુ મદદની જરૂર હોય, તો https://rust-lang.github.io/rustup/installation/windows-msvc.html જુઓ. આ પુસ્તકના

બાકીના ભાગમાં એવા આદેશોનો ઉપયોગ થાય છે જે cmd.exe અને PowerShell બંનેમાં કાર્ય કરે છે. જો કોઈ ચોક્કસ તફાવત હોય, તો અમે કયો વાપરવો તે સમજાવીશું.

### મુશ્કેલીનિવારણ

તપાસ કરવા કે તમે યોગ્ય રીતે Rust સ્થાપિત કર્યું છે કે નહીં, તો એક શેલ ખોલો અને આ લીટી દાખલ કરો: `

$ rustc --version
તમારે નવીનતમ સ્થિર આવૃત્તિ માટે સંસ્કરણ નંબર, કમિટ હેશ અને કમિટ તારીખ નીચેના ફોર્મેટમાં જોવી જોઈએ:

rustc x.y.z (abcabcabc yyyy-mm-dd)
જો તમને આ માહિતી દેખાય, તો તમે સફળતાપૂર્વક Rust સ્થાપિત કર્યું છે! જો તમને આ માહિતી ન દેખાય, તો તપાસ કરો કે Rust તમારા `%PATH%` સિસ્ટમ ચલમાં નીચે મુજબ હાજર છે. વિન્ડોઝ

CMD માં, આનો ઉપયોગ કરો:

> echo %PATH%
પાવરશેલમાં, ઉપયોગ કરો:

> echo $env:Path
લિનક્સ અને મેકઓએસમાં, ઉપયોગ કરો:

$ echo $PATH
જો આ બધું યોગ્ય હોય અને Rust હજી કાર્યરત ન થતું હોય, તો તમે મદદ મેળવી શકો તેવાં ઘણા સ્થળો છે. સમુદાય પાનાં પર અન્ય Rustaceans (આપણે આપણને આપેલા એક મૂર્ખ નામ)નો સંપર્ક કેવી રીતે કરવો તે જાણો.

### સુધારણા અને અનિ સ્થાપન Rust ને સુધારવા માટે, `rustup update` આદેશ ચલાવો. જો તમે કોઈ ચોક્કસ Rust આવૃત્તિ પર પાછા જવા માંગતા હો, તો `rustup install <version>` નો ઉપયોગ કરો અને પછી `rustup default <version>` થી તેને ડિફૉલ્ટ તરીકે સેટ કરો. Rust ને અનિ સ્થાપિત કરવા માટે, `rustup self uninstall` આદેશ ચલાવો. આ તમારા સિસ્ટમમાંથી Rust, rustup અને cargo ને દૂર કરશે.

એકવાર Rust `rustup` દ્વારા સ્થાપિત થઈ જાય પછી, નવું પ્રકાશિત સંસ્કરણ અપડેટ કરવું સરળ છે. તમારા શેલમાંથી, નીચેની અપડેટ સ્ક્રિપ્ટ ચલાવો:

$ rustup update
રસ્ટ અને `rustup` દૂર કરવા માટે, તમારા શેલમાંથી નીચેની અનઇન્સ્ટોલ સ્ક્રિપ્ટ ચલાવો:

$ rustup self uninstall

### સ્થાનિક દસ્તાવેજીકરણ વાંચવું

રસ્ટનું સ્થાપન સ્થાનિક રીતે દસ્તાવેજનો નકલ પણ સામેલ કરે છે જેથી તમે તેને ઓફલાઈનમાં વાંચી શકો. તમારા બ્રાઉઝરમાં સ્થાનિક દસ્તાવેજ ખોલવા માટે `rustup doc` ચલાવો. જ્યારે પણ કોઈ પ્રકાર અથવા

કાર્ય પ્રમાણિત લાયબ્રેરી દ્વારા આપવામાં આવે અને તમને ખબર ન હોય કે તે શું કરે છે અથવા તેનો ઉપયોગ કેવી રીતે કરવો, તો માહિતી મેળવવા માટે એપ્લિકેશન પ્રોગ્રામિંગ ઈન્ટરફેસ (API) દસ્તાવેજનો ઉપયોગ કરો!

### ટેક્સ્ટ સંપાદકો અને આદર્શ વાપરવા Rust કોડ લખવા માટે, તમે કોઈપણ ટેક્સ્ટ સંપાદકનો ઉપયોગ કરી શકો છો. જો કે, Rustના વિકાસને સરળ બનાવવા માટે ઘણાં આદર્શો (IDEs) ઉપલબ્ધ છે જે ખાસ કરીને Rust માટે રચાયેલાં છે. આ આદર્શો સામાન્ય રીતે કોડ પૂર્ણતા, સિન્ટેક્સ હાઇલાઇટિંગ અને ડીબગીંગ જેવાં કાર્યો પૂરાં પાડે છે. તમે `rustup` દ્વારા ઇન્સ્ટોલ કરેલાં આદર્શોનો ઉપયોગ કરી શકો છો અથવા તમે કોઈ અન્ય સંપાદક (editor) પસંદ કરી શકો છો. ઘણાં લોકપ્રિય સંપાદકો Rust માટે પ્લગઇન્સ (plugins) ધરાવે છે જે વિકાસની પ્રક્રિયાને વધારે છે. Rust પ્રોજેક્ટ્સ બનાવવા અને સંચાલિત કરવા માટે `cargo` એક શક્તિશાળી સાધન છે. આ `cargo` તમને `crate` બનાવવામાં, નિર્ભરતાનું સંચાલન કરવામાં અને `compiler` ચલાવવામાં મદદ કરે છે. `linker` પણ `cargo` દ્વારા સંચાલિત થાય છે. જો તમે નવા છો, તો તમે Visual Studio Code (VS Code) જેવાં આદર્શોનો ઉપયોગ કરવાનું વિચારી શકો છો, જેમાં Rust Analyzer નામનું એક સારું પ્લગઇન ઉપલબ્ધ છે. આ પ્લગઇન તમને કોડ લખતી વખતે મદદરૂપ થાય છે અને `compiler` તરફથી મળતી ભૂલો અને ચેતવણીઓ દર્શાવે છે. તમે જે સંપાદક (editor) અથવા આદર્શ (IDE) પસંદ કરો છો, તે તમારી કાર્યક્ષમતામાં વધારો કરી શકે છે અને Rust શીખવામાં તમને મદદરૂપ થઈ શકે છે.

આ પુસ્તક એ ધારણા કરતું નથી કે તમે Rust કોડ લખવા માટે કયા સાધનો વાપરો છો. લગભગ કોઈપણ ટેક્સ્ટ સંપાદક કાર્ય પૂર્ણ કરી શકે છે! જોકે, ઘણા ટેક્સ્ટ સંપાદકો અને સંકલિત વિકાસ પર્યાવરણો (IDEs) માં Rust માટે બનેલું સમર્થન હોય છે. તમે હંમેશાં Rust વેબસાઇટ પરના સાધનો પાનાં પર ઘણા સંપાદકો અને IDEsની પ્રમાણમાં વર્તમાન યાદી શોધી શકો છો.

### આ પુસ્તક સાથે ઓફલાઈન કાર્ય કરવું.

ઘણી ઉદાહરણોમાં, આપણે પ્રમાણભૂત લાયબ્રેરીથી આગળના Rust પેકેજોનો ઉપયોગ કરીશું. તે ઉદાહરણો દ્વારા કાર્ય કરવા માટે, તમારે ઇન્ટરનેટ કનેક્શનની જરૂર પડશે અથવા તો નિર્ભારીતાઓને અગાઉથી ડાઉનલોડ કરવાની રહેશે. નિર્ભારીતાઓને અગાઉથી ડાઉનલોડ કરવા માટે, તમે નીચેના આદેશો ચલાવી શકો છો. (અમે `cargo` શું છે અને આ દરેક આદેશો શું કરે છે તે પછીથી વિગતવાર સમજાવીશું.)

$ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.8.5 trpl@0.2.0
આ ક્રિયાક્રમ આ પેકેજો માટે ડાઉનલોડ્સને કેશ કરશે, જેથી તમારે ભવિષ્યમાં તેમને ફરીથી ડાઉનલોડ કરવાની જરૂર નહીં પડે. એકવાર તમે આ આદેશ ચલાવી લો, પછી તમારે `get-dependencies` ફોલ્ડર રાખવાની જરૂર નથી. જો તમે આ આદેશ ચલાવ્યો હોય, તો પુસ્તકના બાકીના ભાગમાં બધા `cargo` આદેશો સાથે `--offline` ધ્વજ વાપરી શકો છો, જેથી નેટવર્કનો ઉપયોગ કરવાનો પ્રયાસ કરવાને બદલે આ કેશ્ડ સંસ્કરણોનો ઉપયોગ કરી શકાય.
