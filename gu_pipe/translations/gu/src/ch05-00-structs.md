# Using Structs to Structure Related Data

એક `struct`, અથવા રચના, એ એક કસ્ટમ ડેટા પ્રકાર છે જે તમને બહુવિધ સંબંધિત મૂલ્યોને એકસાથે પેક કરવાની અને તેને અર્થપૂર્ણ જૂથ તરીકે નામ આપવાની મંજૂરી આપે છે. જો તમે ઑબ્જેક્ટ-ઓરિએન્ટેડ ભાષાથી પરિચિત છો, તો `struct` એ ઑબ્જેક્ટના ડેટા એટ્રિબ્યુટ્સ જેવું હોય છે. આ પ્રકરણમાં, અમે તમારા માટે પહેલાથી જ જાણીતા હોય તેવાં બાબતો પર આધાર રાખીને ટ્યૂપલ્સની તુલના `struct` સાથે કરીશું અને `struct` ક્યારે ડેટા જૂથ બનાવવા માટે વધુ સારો માર્ગ છે તે દર્શાવીશું.

અમે `struct` ને વ્યાખ્યાયિત (define) અને ઇન્સ્ટૅન્સિએટ (instantiate) કેવી રીતે કરવું તે પ્રદર્શિત કરીશું. અમે એસોસિએટેડ ફંક્શન્સ (associated functions), વિશેષ કરીને મેથડ્સ (methods) પ્રકારના એસોસિએટેડ ફંક્શન્સને વ્યાખ્યાયિત કરવાની ચર્ચા કરીશું, જે `struct` પ્રકાર સાથે સંકળાયેલ વર્તનને સ્પષ્ટ કરે છે. `Struct` અને `enum` (પ્રકરણ ૬ માં ચર્ચા કરવામાં આવી છે) તમારા પ્રોગ્રામના ડોમેનમાં નવા પ્રકારો બનાવવા માટેનાં પથ્થર છે, જેથી કરીને Rust ની કમ્પાઇલ-ટાઇમ ટાઈપ ચેકિંગનો સંપૂર્ણ લાભ લઈ શકાય.
