ધ રસ્ટ પ્રોગ્રામિંગ લેંગ્વેજ (ગુજરાતી) - પ્રકરણ 1

નમસ્કાર, દુનિયા!

હવે તમે Rust સ્થાપિત કરી લીધું છે, તો હવે પહેલો Rust કાર્યક્રમ લખવાનો સમય આવી ગયો છે. નવી ભાષા શીખતી વખતે એક નાનો કાર્યક્રમ લખવાની પરંપરા હોય છે જે Hello, world! શબ્દમાળાને પડદા પર છાપે છે, તેથી આપણે અહીં પણ એવું જ કરીશું!

નોંધ: આ પુસ્તક કમાન્ડ લાઇનથી પૂર્વપરિચય હોવાનું માની લે છે. Rust તમારા સંપાદન અથવા સાધનો વિશે કે તમારો કોડ ક્યાં રહે છે તે વિશે કોઈ ચોક્કસ માંગણી કરતું નથી, તેથી જો તમે કમાન્ડ લાઇનને બદલે IDE વાપરવાનું પસંદ કરો છો, તો તમારા મનપસંદ IDE નો ઉપયોગ કરવા નિઃસંકોચ રહો. ઘણા IDEs હવે Rust માટે અમુક અંશે સમર્થન ધરાવે છે; વિગતો માટે IDE ના દસ્તાવેજો તપાસો. Rust ટીમ rust-analyzer દ્વારા મહાન IDE સમર્થનને સક્ષમ કરવા પર ધ્યાન કેન્દ્રિત કરી રહી છે. વધુ વિગતો માટે Appendix D જુઓ.

પ્રોજેક્ટ ડિરેક્ટરી સ્થાપન

તમે પ્રથમ તમારા Rust કોડને સંગ્રહિત કરવા માટે એક ડિરેક્ટરી બનાવશો. Rust ને તમારા કોડ ક્યાં રહે છે એ મહત્વનું નથી, પરંતુ આ પુસ્તકમાં આપેલ કસરતો અને પ્રોજેક્ટ્સ માટે, અમે તમારા હોમ ડિરેક્ટરીમાં projects નામની ડિરેક્ટરી બનાવવા અને તમારા બધા પ્રોજેક્ટ્સ ત્યાં રાખવાની

ભલામણ કરીએ છીએ. એક ટર્મિનલ ખોલો અને projects ડિરેક્ટરી અને “Hello, world!” પ્રોજેક્ટ માટે એક ડિરેક્ટરી બનાવવા માટે નીચેના આદેશો દાખલ કરો. Linux, macOS,

અને Windows પર PowerShell માટે, આ દાખલ કરો:

$ mkdir ~/projects $ cd ~/projects $ mkdir hello_world $ cd hello_world વિન્ડોઝ CMD માટે, આ દાખલ કરો:

mkdir “%USERPROFILE%\projects” cd /d “%USERPROFILE%\projects” mkdir hello_world cd hello_world

રસ્ટ પ્રોગ્રામની મૂળભૂત બાબતો આ પ્રકરણમાં, તમે રસ્ટ પ્રોગ્રામના મૂળભૂત ઘટકો વિશે શીખશો. દરેક રસ્ટ પ્રોગ્રામ main નામનું એક કાર્ય ધરાવે છે. આ કાર્ય એ છે જ્યાં પ્રોગ્રામનો અમલ શરૂ થાય છે. અહીં એક સરળ રસ્ટ પ્રોગ્રામનું ઉદાહરણ આપેલું છે: rust fn main() { println!("Hello, world!"); } આ પ્રોગ્રામ Hello, world! શબ્દમાળાને કન્સોલ પર છાપે છે. ચાલો આ પ્રોગ્રામના દરેક ભાગને સમજીએ. fn કીવર્ડનો ઉપયોગ એક નવું કાર્ય વ્યાખ્યાયિત કરવા માટે થાય છે. main એ કાર્યનું નામ છે. () કૌંસ સૂચવે છે કે આ કાર્ય કોઈ દલીલો સ્વીકારતું નથી. {} બ્લોક કાર્યના કોડને સમાવે છે. println! એ એક મેક્રો છે જે આપેલ શબ્દમાળાને કન્સોલ પર છાપે છે. ! સૂચવે છે કે આ એક મેક્રો છે, કાર્ય નથી. આ પ્રોગ્રામને ચલાવવા માટે, તેને ફાઇલ તરીકે સાચવો, ઉદાહરણ તરીકે main.rs, અને પછી તમારા ટર્મિનલમાં નીચેનો આદેશ ચલાવો: rustc main.rs આ એક એક્ઝિક્યુટેબલ ફાઇલ બનાવશે જેને તમે ચલાવી શકો છો. તમે rustup નો ઉપયોગ કરીને રસ્ટ ઇન્સ્ટોલ કરી શકો છો. cargo એ રસ્ટનું પેકેજ મેનેજર છે, જેનો ઉપયોગ પ્રોજેક્ટ બનાવવા અને સંચાલિત કરવા માટે થાય છે. સંકલક (compiler) તમારા કોડને મશીન કોડમાં ફેરવે છે, જ્યારે લિંકર (linker) વિવિધ ક્રેટ્સ (crates) ને એકસાથે જોડીને એક્ઝિક્યુટેબલ બનાવે છે.

ત્યારબાદ, એક નવી સ્ત્રોત ફાઈલ બનાવો અને તેને main.rs નામ આપો. Rust ફાઈલો હંમેશાં .rs એક્સ્ટેન્શન સાથે સમાપ્ત થાય છે. જો તમે તમારી ફાઇલનામમાં એક કરતાં વધુ શબ્દનો ઉપયોગ કરી રહ્યા છો, તો સંમેલન મુજબ તેમને અન્ડરસ્કોરથી અલગ કરો. ઉદાહરણ તરીકે, hello_world.rs નો ઉપયોગ કરોhelloworld.rs ને બદલે.

હવે તમે બનાવેલી main.rs ફાઈલ ખોલો અને લિસ્ટિંગ 1-1 માં આપેલ કોડ દાખલ કરો.

fn main() { println!("Hello, world!"); } ફાઈલને સાચવો અને તમારા ટર્મિનલ વિન્ડોમાં પાછા જાઓ જે ~/projects/hello_world ડિરેક્ટરીમાં છે. લિનક્સ અથવા મેકઓએસ પર, ફાઈલને સંકલિત કરવા (compile) અને ચલાવવા માટે નીચેના આદેશો દાખલ કરો:

$ rustc main.rs $ ./main Hello, world! વિન્ડોઝ પર, આદેશ .\main દાખલ કરો, ‎./main ને બદલે.

rustc main.rs .\main Hello, world! તમારા ઓપરેટિંગ સિસ્ટમ ગમે તે હોય, શબ્દમાળા Hello, world! ટર્મિનલ પર છાપાવા જોઈએ. જો તમને આ પરિણામ ન દેખાય, તો સ્થાપન વિભાગના “મુશ્કેલીનિવારણ” ભાગમાં મદદ મેળવવા માટેની રીતો જુઓ.

જો Hello, world! છાપાયું હોય, તો અભિનંદન! તમે સત્તાવાર રીતે એક Rust કાર્ય લખ્યું છે. એ તમને એક Rust પ્રોગ્રામર બનાવે છે—સ્વાગત છે!

રસ્ટ કાર્યક્રમની રચના

ચાલો આ “હેલ્લો, વર્લ્ડ!” કાર્યક્રમને વિગતવાર જોઈએ. અહીં કોયડાનો પહેલો ભાગ છે:

fn main() {

} આ લીટીઓ એક કાર્ય વ્યાખ્યાયિત કરે છે જેનું નામ main છે. main કાર્ય વિશેષ છે: તે દરેક ચલાવવા યોગ્ય Rust કાર્યક્રમમાં પ્રથમ કોડ તરીકે ચાલે છે. અહીં, પ્રથમ લીટી એક કાર્ય જાહેર કરે છે જેનું નામ main છે જે કોઈ પરિમાણો ધરાવતું નથી અને કંઈપણ પરત કરતું નથી. જો પરિમાણો હોત, તો તે કૌંસની અંદર ( () ) જશે.

કાર્ય શરીર {} માં લપટેલું છે. Rust ને તમામ કાર્ય શરીરોને કર્લી બ્રેકેટની આસપાસ આવશ્યક છે. કાર્ય ઘોષણાની સમાન લીટી પર ખૂલતું કર્લી બ્રેકેટ મૂકવું એ સારી શૈલી છે, તેમની વચ્ચે એક જગ્યા ઉમેરવી.

નોંધ: જો તમે બધાં Rust પ્રોજેક્ટમાં એકસમાન શૈલી જાળવવા માંગતા હો, તો તમે rustfmt નામનું આપોઆપ ફોર્મેટિંગ સાધન વાપરી શકો છો જે તમારા કોડને ચોક્કસ શૈલીમાં ફોર્મેટ કરે છે (વધુ માહિતી rustfmt વિશે Appendix D માં મળશે). Rust ટીમ આ સાધન સ્ટાન્ડર્ડ Rust વિતરણ સાથે સામેલ કર્યું છે, જેમ કે rustc, તેથી તે પહેલાથી જ તમારા કમ્પ્યુટર પર ઇન્સ્ટોલ થયેલ હોવું જોઈએ!

main કાર્યનો મુખ્ય ભાગ નીચેના કોડ ધરાવે છે:

println!(“Hello, world!”); આ લીટી આ નાનકડા કાર્યક્રમમાં બધું જ કાર્ય કરે છે: તે છબી પર લખાણ છાપે છે. અહીં ત્રણ મહત્વપૂર્ણ વિગતો ધ્યાન રાખવા જેવી છે.

પ્રથમ, println! એક Rust મેક્રોને બોલાવે છે. જો તેના બદલે કોઈ કાર્ય બોલાવવામાં આવ્યું હોત, તો તેને println ( ! વગર) તરીકે દાખલ કરવામાં આવતું હોત. Rust મેક્રો એ કોડ લખવાનો એક માર્ગ છે જે Rust વાક્યરચનાને વિસ્તારવા માટે કોડ જનરેટ કરે છે, અને આપણે તેના વિશે પ્રકરણ ૨૦ માં વધુ વિગતવાર ચર્ચા કરીશું. અત્યારે, તમારે ફક્ત એટલું જાણવું જરૂરી છે કે ! નો ઉપયોગ કરવો એ સામાન્ય કાર્યને બદલે મેક્રોને બોલાવવાનો અર્થ થાય છે અને મેક્રો કાર્યો જેટલા નિયમોનું પાલન કરતા નથી.

બીજું, તમે "Hello, world!" શબ્દમાળા જુઓ છો. અમે આ શબ્દમાળાને println! ને દલીલ તરીકે પસાર કરીએ છીએ, અને શબ્દમાળા દેખાવમાં છપાય છે. ત્રીજું, અમે લીટીને

અર્ધવિરામચિહ્ન ( ; ) સાથે સમાપ્ત કરીએ છીએ, જે દર્શાવે છે કે આ અભિવ્યક્તિ પૂર્ણ થઈ ગઈ છે, અને આગલી શરૂ થવા માટે તૈયાર છે. મોટાભાગની Rust કોડની લીટીઓ અર્ધવિરામચિહ્ન સાથે સમાપ્ત થાય છે.

સંકલન અને અમલ જ્યારે તમે rustc આદેશ વાપરો છો, ત્યારે સંકલક તમારા સ્રોત કોડને મશીન કોડમાં ફેરવે છે. આ પ્રક્રિયામાં ઘણાં તબક્કાઓ શામેલ હોય છે, જેમાં તપાસણી, વિસ્તરણ અને કોડ નિર્માણનો સમાવેશ થાય છે. સંકલન પછી, લિંકર ઑબ્જેક્ટ ફાઇલોને એકસાથે જોડીને એક્ઝિક્યુટેબલ ફાઇલ બનાવે છે. આ ફાઇલમાં તમારા પ્રોગ્રામ માટે જરૂરી તમામ કોડ હોય છે. cargo run આદેશ સંકલન અને અમલ બંને કરે છે. જો સ્રોત કોડ પહેલેથી જ સંકલિત થયેલ હોય, તો લિંકર ફક્ત ઑબ્જેક્ટ ફાઇલોને જોડીને એક્ઝિક્યુટેબલ ફાઇલ બનાવશે. પછી, સિસ્ટમ એક્ઝિક્યુટેબલ ફાઇલ ચલાવે છે. જો તમે cargo build વાપરી રહ્યા છો, તો તે માત્ર સંકલન કરે છે અને એક્ઝિક્યુટેબલ ફાઇલ બનાવે છે, પરંતુ તેને ચલાવતું નથી. તમારે તેને ચલાવવા માટે cargo run નો ઉપયોગ કરવો પડશે. સંકલન પ્રક્રિયા દરમિયાન, સંકલક તમારા કોડમાં રહેલી ભૂલોને શોધી કાઢે છે. આ ભૂલોમાં પ્રકારની અસંગતતા, વ્યાકરણની ભૂલો અને સલામતીના ઉલ્લંઘનો શામેલ હોઈ શકે છે. જો સંકલકમાં કોઈ ભૂલ જણાય, તો તે તમને ચેતવણી આપશે અને સંકલન પ્રક્રિયા બંધ કરી દેશે. એકવાર તમારો કોડ સફળતાપૂર્વક સંકલિત થઈ જાય, પછી તમે તેને ચલાવી શકો છો. જ્યારે પ્રોગ્રામ ચાલે છે, ત્યારે તે સ્મૃતિમાં કોડ અને ડેટા લોડ કરે છે. પછી, પ્રોસેસર કોડના નિર્દેશોને એક પછી એક એક્ઝિક્યુટ કરે છે.

તમે હમણાં જ એક નવું બનાવેલું કાર્ય ચલાવ્યું છે, તેથી ચાલો પ્રક્રિયાના દરેક તબક્કાની તપાસ કરીએ.

Rust કાર્ય ચલાવતા પહેલાં, તમારે તેને Rust સંકલકનો ઉપયોગ કરીને સંકલિત કરવું આવશ્યક છે, જેમાં rustc આદેશ દાખલ કરવો અને તમારા સ્ત્રોત ફાઇલનું નામ પસાર કરવું જરૂરી છે, જેમ કે આ:

$ rustc main.rs જો તમને C અથવા C++ નો અનુભવ હોય, તો તમે નોંધશો કે આ gcc અથવા clang જેવું જ છે. સફળતાપૂર્વક સંકલન કર્યા પછી, Rust એક દ્વિસંગી ચલાવવા યોગ્ય ફાઇલ ઉત્પન્ન

કરે છે. Linux, macOS અને Windows પર PowerShell માં, તમે તમારા શેલમાં ls આદેશ દાખલ કરીને ચલાવવા યોગ્ય ફાઇલ જોઈ શકો છો:

$ ls main main.rs લિનક્સ અને મેકઓએસ પર, તમને બે ફાઇલો દેખાશે. વિન્ડોઝ પર પાવરશેલ સાથે, તમને એ જ ત્રણ ફાઇલો દેખાશે જે તમે CMD નો ઉપયોગ કરીને જોશો. વિન્ડોઝ પર CMD સાથે, તમે નીચે મુજબ દાખલ કરશો:

dir /B %= the /B option says to only show the file names =% main.exe main.pdb main.rs આ .rs એક્સ્ટેંશનવાળી સ્ત્રોત કોડ ફાઇલ, ચલાવવા યોગ્ય ફાઇલ (Windows પર main.exe, પરંતુ અન્ય તમામ પ્લેટફોર્મ પર main), અને Windows વાપરતી વખતે, ડિબગીંગ માહિતી ધરાવતી .pdb એક્સ્ટેંશનવાળી ફાઇલ દર્શાવે છે. અહીંથી, તમે main અથવા main.exe ફાઇલ ચલાવો છો, આ રીતે:

$ ./main # or .\main on Windows જો તમારી main.rs ફાઇલ તમારી “Hello, world!” કાર્યક્રમ છે, તો આ લીટી તમારા ટર્મિનલ પર Hello, world! છાપે છે.

જો તમે ગતિશીલ ભાષા (dynamic language) જેમ કે રૂબી, પાયથોન અથવા જાવાસ્ક્રિપ્ટથી વધુ પરિચિત છો, તો તમને એક કાર્યક્રમને અલગ પગલાં તરીકે સંકલિત (compile) અને ચલાવવાની આદત ન હોઈ શકે. Rust એ ahead-of-time સંકલિત ભાષા છે, જેનો અર્થ થાય છે કે તમે એક કાર્યક્રમનું સંકલન કરી શકો છો અને તે ચલાવવા યોગ્ય ફાઇલ કોઈ બીજાને આપી શકો છો, અને તેઓ Rust ઇન્સ્ટોલ કર્યા વિના પણ તેને ચલાવી શકે છે. જો તમે કોઈને .rb , .py , અથવા .js ફાઇલ આપો, તો તેમને રૂબી, પાયથોન અથવા જાવાસ્ક્રિપ્ટ અમલીકરણ (implementation) ઇન્સ્ટોલ કરવું જરૂરી છે (ક્રમશઃ). પરંતુ તે ભાષાઓમાં, તમારે તમારા કાર્યક્રમને સંકલિત અને ચલાવવા માટે ફક્ત એક જ આદેશની જરૂર પડે છે. ભાષા ડિઝાઇન (language design) માં બધું જ આપ-લે (trade-off) છે.

ફક્ત rustc સાથે સંકલન કરવું સરળ કાર્યક્રમો માટે ઠીક છે, પરંતુ જેમ જેમ તમારું પ્રોજેક્ટ વધે તેમ, તમારે બધા વિકલ્પોનું વ્યવસ્થાપન કરવું અને તમારા કોડને વહેંચવાનું સરળ બનાવવું પડશે. હવે પછી, અમે તમને Cargo સાધનથી પરિચિત કરાવશું, જે તમને વાસ્તવિક દુનિયાના Rust કાર્યક્રમો લખવામાં મદદ કરશે.
