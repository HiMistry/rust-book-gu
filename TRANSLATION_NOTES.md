# Rust Book Gujarati Translation — Notes

## Overview

This is a fully-automated translation of **The Rust Programming Language** 
([doc.rust-lang.org/book/](https://doc.rust-lang.org/book/)) from English into 
Gujarati using a local Ollama model (Gemma3:12b). The translation pipeline is 
written in Rust and uses the `pulldown-cmark` library to parse markdown, 
translate prose paragraphs via Ollama's API, and rebuild the markdown preserving 
all structure (headings, code blocks, inline code, lists, etc.).

## Pipeline

- **Repository**: [github.com/HiMistry/rust-book-gu](https://github.com/HiMistry/rust-book-gu)
- **Pipeline code**: `gu_pipe/translate/`
- **Source (English)**: `book/src/` (original Rust book)
- **Translated output**: `gu_pipe/translations/gu/src/`
- **HTML output**: `gu_pipe/translations/gu/book/` (generated by mdbook)

## Pilot Process

We started with **Chapter 1** (4 files: ch01-00 through ch01-03) as a pilot to 
validate the translation quality before committing to the full ~4-hour run of 
all 112 files.

### Pilot decisions made:

1. **Glossary emptied** → `gu_pipe/glossary.json` set to `{}`. Initially we had 
   38 forced Gujarati translations for Rust terms (ownership → માલિકી, borrowing 
   → ઉધાર, etc.). We removed all of them to let the model translate freely based 
   on context, which produces more natural output.

2. **Sanskrit-origin rule**: The system prompt explicitly instructs the model to 
   use Sanskrit-origin (તત્સમ/તદ્ભવ) Gujarati words and avoid Persian/Farsi/Arabic 
   loanwords. This is a deliberate choice for a more formal, scholarly register.

3. **English terms preserved**: A comprehensive list of technical terms are kept 
   in English (see below).

4. **Heading fix**: Headings are merged with their following paragraph in the 
   prompt (for context), and the `#` markers are stripped before word-proportional 
   splitting to prevent them from leaking into paragraph text.

## Translation Rules (system_prompt)

The system prompt in `gu_pipe/config.json` enforces:

1. **Sanskrit-origin only** — avoid Persian/Farsi/Arabic loanwords
2. **English terms preserved** — technical/programming terms stay in English
3. **Inline code preserved** — `` `code` `` kept as-is
4. **Headings keep `##` prefix** in output
5. **No explanations** — output only the translation

## English Terms Kept As-Is

These terms remain in English in the Gujarati translation:

Rust, rustup, cargo, compiler, linker, trait, enum, struct, macro, crate, module,
String, Vec, HashMap, ownership, borrowing, reference, lifetime, loop, match,
variable, function, closure, iterator, thread, error, warning, test, type, value,
memory, stack, heap, pointer, install, uninstall, step, file, directory, path,
browser, application, database, keyboard, mouse, terminal, command, tool, library,
package, dependency, project, binary, executable, API, IDE, URL, HTTPS, HTTP,
JSON, TOML, YAML, HTML, CSS, JavaScript, Unicode, UTF-8

## Words to Avoid (Persian/Farsi/Arabic → Sanskrit-origin replacement)

| Avoid (Persian/Arabic) | Use instead (Sanskrit) |
|------------------------|----------------------|
| શરૂ (start) | આરંભ |
| ખાસ (special) | વિશેષ |
| ફક્ત (only) | માત્ર |
| સવાલ (question) | પ્રશ્ન |
| જવાબ (answer) | ઉત્તર |
| તારીખ (date) | તિથિ |
| શહેર (city) | નગર |
| દરવાજો (door) | દ્વાર |
| કિમત (price) → *Sanskrit ok | મૂલ્ય |

Colloquial Sanskrit-derived words like કારણ, કાર્ય, સમય, પ્રયત્ન are fine.

## Known Issues

1. **HTML tags from generics**: The model translates Rust generic type parameters
   like `<T>` into Gujarati text like `<તા>`, which mdbook interprets as HTML tags.
   This produces HTML warnings but does not break the output.

2. **Listings path**: mdbook preprocessor includes (`{{#rustdoc_include ...}}`) 
   reference relative paths that don't exist in the translation directory. The 
   HTML output works but shows warnings about missing listing files.

3. **SUMMARY.md**: Originally the pipeline flattened the SUMMARY.md into plain 
   text (lost all links). We restored the original English SUMMARY.md for navigation.
